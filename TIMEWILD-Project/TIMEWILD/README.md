# 🎮 3D Platformer Starter Kit

## 📖 Story

ระหว่างการทดลองเดินทางข้ามเวลา เครื่องย้อนเวลาของนักสำรวจเกิดขัดข้อง ทำให้เขาหลุดมายังโลกยุคดึกดำบรรพ์ที่เต็มไปด้วยไดโนเสาร์ และชิ้นส่วนพลังงาน Chronoshard กระจัดกระจายไปทั่วพื้นที่

ผู้เล่นต้องออกตามหาชิ้นส่วนเหล่านี้เพื่อเปิดประตูเวลา โดยอาศัยความคล่องตัวหลบไดโนเสาร์ ข้ามแม่น้ำ และผ่านกับดักธรรมชาติ แต่ประตูแต่ละแห่งกลับพาไปยังพื้นที่ที่อันตรายยิ่งขึ้น

## เปิดโปรเจกต์

ใช้ Godot 4.7 เปิดไฟล์ `project.godot` รอ Import ให้เสร็จ แล้วกด F5 เพื่อเล่น

WASD เคลื่อนที่ / เมาส์ปรับมุมกล้อง / Space กระโดดและกระโดดสองครั้ง / Esc พักเกม / R เริ่มด่านใหม่

เก็บ Chronoshard ให้ครบ 6 ชิ้นต่อด่าน แล้วเข้าประตูเวลา ผ่านทั้งหมด 3 ด่านเพื่อกลับบ้าน
